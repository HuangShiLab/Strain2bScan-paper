# Recovered StrainScan head-to-head run artifacts

These are the StrainScan outputs recovered from the original 15-species comparison. They include four
single-species run directories and three multi-species community run directories, one species subdirectory per
per-species StrainScan invocation. They are not the complete 204/12 run set required to regenerate every
published aggregate row, but they preserve the available raw `final_report.txt`, cluster votes, logs, and
run metadata. `checksums.sha256` records all files.

The complete set can only be regenerated with a pinned StrainScan container, per-species databases, the exact
read subsets, and the original driver. The manuscript states this limitation.
