# Rhesus macaque 148-sample spatial strain cohort: manuscript summary tables

These curated tables support the real-cohort Results paragraphs and Methods subsection.
The source run and full output tables were generated on HKU HPC under
`/lustre1/g/aos_shihuang/projects/monkey_strain2bscan/analysis/full_148_20261027/`,
`.../analysis/strain_profiling_20261023/`, and
`.../analysis/functional_coupling_20261027/`. HPC outputs and analysis scripts were synchronized locally under
`hpc_outputs/` on 2026-11-03. `hpc_output_verification.tsv` records the key cohort,
profiling, spatial and coupling counts reproduced directly from those raw outputs.

Cohort: 148 samples = 128 GI spatial samples (66 luminal, 62 mucosal) + 20 body controls.
Four vendor throat/trachea files were excluded. Calls are 0.95 strain-cluster calls.
