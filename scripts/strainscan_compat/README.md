# StrainScan compatibility patches

These files document the minimal changes required to run the original Python
StrainScan (https://github.com/liaoherui/StrainScan) on the HPC2021 cluster
used for the Strain2bScan-paper benchmarks.

## Files

- `Rscript_shim.py` – drop-in replacement for `Rscript` when R is not
  installed. It parses the `tem_hier.R` file generated by StrainScan and
  reproduces R's `hclust(..., method="single")` + `cutree(h=...)` output using
  `scipy.cluster.hierarchy`. Place it on `PATH` as `Rscript`.

- `select_rep.py` – patched version of StrainScan's
  `library/select_rep.py`. Replaces the deprecated `np.float` alias with the
  builtin `float` so the code works with NumPy >= 1.20.

## Usage

```bash
# build seqpy for the target Python version
cd StrainScan/library
python setup.py build_ext --inplace

# put shim on PATH before the real Rscript
export PATH=/path/to/strainscan_compat:$PATH

# run build
python StrainScan/StrainScan_build.py -i genomes/ -o db/
```
